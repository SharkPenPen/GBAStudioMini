# 18 · PC 窗口与调试（v1）

> 2026-11-05。PC 播放器的窗口、视角、调试信息。

## 0. 窗口

- 逻辑尺寸 480×272（PSP 全幅）。
- 默认 2×（960×544）；可选 1×/2×/3×。
- 窗口可调大小，但保持 480:272 比例，只做整数缩放。
- 最近邻采样，不用双线性。
- 不做自由拉伸。
- 全屏以后加。

## 1. 视角

- 默认 --view=psp：480×272。
- --view=3ds：400×240 安全区。
- 编辑器两个都能预览。

## 2. 调试（F1）

- 帧率、帧号。
- 场景 id。
- 玩家坐标、速度、是否落地。
- 相机位置。
- 碰撞盒、区域、对象框。
- 正在触发的规则。
- 变量列表（可选开关）。

## 3. 运行

- 编辑器 F5：导出 p3d → 启动 player。
- 命令行：--p3d FILE、--view psp|3ds、--frames N、--report FILE、--auto、--scale N。
- 鼠标只有编辑器用。

## 4. v1 不做

- 全屏。
- 多窗口。
- 热重载。
- 手柄。
- 截图/录像。
