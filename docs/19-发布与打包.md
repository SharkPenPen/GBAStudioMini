# 19 · 发布与打包

> 2026-11-05。PC 版打包格式、目录和校验方式。

## 0. 版本

- 版本号在 `VERSION.txt` 和 `CMakeLists.txt` 的 `project(VERSION ...)` 里。
- 当前 `0.1.0`。

## 1. 打包

~~~powershell
.\tools\package.ps1
~~~

脚本会：

1. 调用 `tools/build-editor.ps1` 构建；
2. 运行 `capabilities.exe`，失败就停止；
3. 复制二进制、文档、空白模板和许可证；
4. 生成 zip 和 sha256。

## 2. 包内容

~~~text
PocketLoom-0.1.0-win64/
  PocketLoom-Editor.exe
  PocketLoom-Play.exe
  ploom.exe
  VERSION.txt
  README.md
  LICENSE
  THIRD_PARTY_NOTICES.md
  docs/
  templates/blank/
  licenses/
~~~

`ploom.exe` 和 `PocketLoom-Editor.exe` 是同一编辑器的两个入口；`PocketLoom-Play.exe` 只读 p3d。

## 3. 校验

~~~text
dist/PocketLoom-0.1.0-win64.zip.sha256
~~~

## 4. 不包含

- toolchain / CMake / Ninja；
- 字体源文件（运行时只使用已生成的 UI 字体头）；
- PSP / 3DS 后端；
- 示例游戏（空白模板在 `templates/blank`）。
