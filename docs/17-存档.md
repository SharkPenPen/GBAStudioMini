# 17 · 存档（v1）

> 2026-11-05。只存“全局变量 + 当前场景 + 玩家位置”，不做对象/规则/触发器快照。

## 0. 范围

存：

- 版本号
- 当前场景 id
- 玩家位置 x/y
- 全局变量（字符串 → 整数）
- 可选：游玩时间、存档时间

不存：

- 场景对象、敌人、子弹
- 触发器的 done 状态
- 规则的动作序列
- 界面状态
- 相机位置

## 1. 读档行为

- 加载场景。
- 写入全局变量。
- 把玩家放到保存的位置。
- 其他一切重置：敌人重生、触发器复位、子弹清空。

## 2. 槽位

- v1 一个槽（save0）。
- 以后加多槽。

## 3. 触发方式

- 规则动作：“存档”“读档”。
- 界面菜单：“继续”“新游戏”。
- 标题界面：有存档才显示“继续”。

## 4. 文件

- 路径由平台层给：PC 用游戏目录或用户目录；3DS/PSP 用 SD/记忆棒。
- 格式：小二进制，带 magic + 版本；读失败就当没有存档，不崩。
- 版本不同：能读就迁移，不能读就忽略。

## 5. v1 不做

- 多槽。
- 自动存档。
- 对象级快照。
- 云存档。
