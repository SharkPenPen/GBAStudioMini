# 16 · 界面元素（v1）

> 2026-11-05。界面元素、平铺九宫格、文字、数值显示、一层容器。
> 结论：框按 8×8 平铺，不缩放；文字自动换行；面板只做一层容器。

## 0. 元素类型

| 类型 | 说明 |
|---|---|
| panel | 面板/框，平铺九宫格 |
| text | 静态文字，或带数值绑定 |
| image | 静态图片 |
| value_image | 数值 → 显示第 N 帧 |
| value_bar | 数值 → 填充条 |
| value_icons | 数值 → 重复 N 个图标 |
| list | 菜单列表（光标 + 确认） |

每个元素都可以带“显示条件”；每个元素都有锚点、偏移、大小。

## 1. 布局区

每个界面有一个布局区：屏幕 或 安全区。

- 屏幕：3DS 400×240，PSP 480×272。
- 安全区：400×240 居中。
- 锚点和百分比按布局区算。

HUD 用屏幕；对话框想撑满也用屏幕；只有必须让 3DS 看全的东西用安全区。

## 2. 面板：平铺九宫格

不做拉伸，做平铺。

- 四个角：固定 8×8。
- 四条边：8×8 边块重复。
- 中间：纯色填充，或 8×8 中间块重复。
- 框宽高按 8 的倍数吸附；有余数调框大小，不拉伸最后一块。
- 边框厚度用 8 的倍数（8 或 16）。

为什么能对齐：400×240 和 480×272 都是 8 的倍数（50×30 / 60×34 块）。

例子：90% 宽

| | 3DS | PSP |
|---|---|---|
| 布局区宽 | 400 | 480 |
| 90% 宽 | 360 = 45 块 | 432 = 54 块 |
| 文字内容宽 | 360 − 2×边框 | 432 − 2×边框 |

两边都是整块，没有半像素、没有缩放。

## 3. 文字

- 字号：8/10/12/14/16，按字体子集打包。
- 不做缩放；选字号，不放大点阵。
- 对齐：左/中/右，上/中/下。
- 自动换行：是（v1）。
- 行高：从对应字号取。
- 颜色：白色图集 + tint。
- 缺字：画 .notdef，导出报告列出来。
- 只做中文：文字直接写在元素里（字面量），不做 key / 多语言表。
- 数字/标点/字母始终包含：每个字号强制打包 ASCII 32–126（0–9、A–Z、a–z、标点），成本很小。
- 数字显示：text 绑定 + 格式串（%d、%02d:%02d）；像素数字也可以用 value_image 的数字图集。

## 4. 一层容器

- panel 可以装子元素（文字、图片、数值显示）。
- 子元素按 panel 的内容区定位（内容区 = 框内减 padding）。
- 框变宽，子元素宽跟着变，文字重新换行。
- 只做一层：panel 里不能再放 panel。
- 不做滚动容器、拖拽窗口。

## 5. 数值显示

- 绑定：读全局变量 / 场景变量 / 对象属性。
- 映射：等于、线性、分段。
- 表现：第 N 帧、填充条、重复图标、格式化文字。
- 编辑器给一个“值滑杆”，拖动预览 0..max。

## 6. 菜单列表

- v1：一列、上下、绕回、不滚动、按住连发。
- 条目：文字或图片。
- 确认/取消用工程设置里的 ui_confirm / ui_cancel。
- 不做多列、子菜单、鼠标。

## 7. v1 不做

- 任意嵌套容器。
- 滚动容器、拖拽窗口。
- 拉伸九宫格（只做平铺）。
- 世界坐标 UI。
- 界面元素动画（逐字/滑动）。

## 8. 地图 autotile（后置）

- 编辑器功能，不是运行时。
- 16 格（上下左右）或 47 格（八邻域）方案。
- 画地形时按邻居位掩码选图；运行时只存图块索引。
- 等地图画起来再做。
