# 14 · 场景图层（v1）

> 2026-11-05。4 个通用图块层 + 1 个对象层。
> 层的名字只是给人看；实际画序固定。

## 0. 四层

| 名字 | 画序 | 用途 |
|---|---|---|
| 前景 1（对象上） | 对象之后 | 挡住角色的树/墙/前景装饰 |
| 前景 2（对象上） | 对象之后 | 第二层前景 |
| 背景 1（对象下） | 对象之前 | 地面/主背景，通常画这里 |
| 背景 2（最底） | 对象之前 | 最底层背景 |

- 层数固定 4，不加不减。
- 对象层固定夹在“背景”和“前景”之间，不单独设层号。
- 每层可以有自己的视差；不做透明度和染色（以后）。
- 名字改自旧的“层 1～4”；导出仍按 priority 决定前景/背景。

## 1. 对象层

- 所有对象（玩家、箱子、敌人、道具）画在同一个对象层。
- 对象层在背景层之后、前景层之前。
- 前景层（第 1/2 层）会盖住对象；地砖默认应画在背景层（第 3/4 层）。

## 2. 画序

背景 2 → 背景 1 → 对象层 → 前景 2 → 前景 1。

同一层内：图块按格子画；对象按列表顺序画（不做 y 排序）。

## 3. 旧数据

- 旧“层 1～4”读入后仍按 priority 工作。
- 旧“背景/主层/前景”不再单独区分，直接用新名字。
- 第 4 层留作最底背景。

## 4. v1 不做

- 每个对象自带层号/z。
- 对象之间按 y 排序。
- 图层透明度/染色。
- 任意层数、层排序。
- 世界坐标 UI。
