# 14 · 场景图层（v1）

> 2026-11-05。4 个通用图块层 + 1 个可调位置的对象层。
> 结论：层只分序号，不分角色；对象层插在层之间。

## 0. 四层

| 字段 | 说明 |
|---|---|
| 序号 | 1～4，画序（1 最下，4 最上） |
| 名字 | 自由文本，只给人看 |
| 显示 | 开/关 |
| 滚动速度 X/Y | 100 = 跟场景一样；50 = 慢一半；0 = 不动 |
| 图块 | 该层的地图数据 |

- 没有“背景/地面/遮挡物”标签。
- 层数固定 4，不加不减；顺序固定。
- 每层可以有自己的视差；不做透明度和染色（以后）。

## 1. 对象层

- 所有对象（玩家、箱子、敌人、道具）画在同一个“对象层”。
- 对象层的位置是场景的一个数：0～4。
  - 0 = 对象在所有层下面。
  - 2 = 层 1、2 在对象后面，层 3、4 在对象前面。
  - 4 = 对象在所有层上面。
- 这样不用给每个对象设层号，就能做“前景树挡住角色”。

## 2. 画序

层 1 → 层 2 → … → 对象层（在指定位置插入）→ … → 层 4。

同一层内：图块按格子画；对象按列表顺序画（不做 y 排序）。

## 3. 旧数据迁移

- 旧“背景/主层/前景” → 层 1/2/3。
- 旧“前景开关”（盖在角色上）→ 对象层位置 = 2（层 1、2 在角色后，层 3 在角色前）。
- 第 4 层留空。

## 4. v1 不做

- 每个对象自带层号/z（以后）。
- 对象之间按 y 排序（以后）。
- 图层透明度/染色。
- 任意层数、层排序。
- 世界坐标 UI。

## 5. 待定

- 对象层位置是每个场景一个，还是工程一个默认值（建议每场景一个，可覆盖）。
- 层名字是否要出现在导出报告里（方便排查）。
