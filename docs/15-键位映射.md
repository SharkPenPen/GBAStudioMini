# 15 · 键位映射（v1）

> 2026-11-05。引擎只提供物理按键，不提供“菜单/奔跑/确认”等语义动作。
> PC 默认借用 PPSSPP 的 QWERTY 键盘布局（方案 A：保留 PPSSPP 原样）。

## 0. 原则

- 引擎只认物理按钮：方向、×/○/□/△、L/R、Start/Select。
- 不提供“菜单/奔跑/跳跃/确认”等动作；这些由开发者在规则里定义。
- 唯一的语义设置：界面的“确认/取消”按钮（工程设置）。

## 1. 按钮表

| 按钮（PSP 名） | PSP | 3DS（按位置） | PC（PPSSPP 默认） |
|---|---|---|---|
| × | × | B | Z |
| ○ | ○ | A | X |
| □ | □ | Y | A |
| △ | △ | X | S |
| L | L | L | Q |
| R | R | R | W |
| Start | Start | Start | Space |
| Select | Select | Select | V（Enter 备用） |
| 上 | 十字键上 / 摇杆上 | 十字键上 / 摇杆上 | ↑ / I |
| 下 | 十字键下 / 摇杆下 | 十字键下 / 摇杆下 | ↓ / K |
| 左 | 十字键左 / 摇杆左 | 十字键左 / 摇杆左 | ← / J |
| 右 | 十字键右 / 摇杆右 | 十字键右 / 摇杆右 | → / L |

- 引擎内部用四个通用按钮 ID；编辑器按平台显示 ×○□△ 或 A/B/X/Y。
- PC 的 A/X 键和“按钮 A/X”同名但不同事，表里以“按钮”列为准。

## 2. 输入状态

每个按钮三个状态：按下（边沿）、按住、松开（边沿）。

规则里的条件直接对应：key_down / key_pressed / key_up / key_held。

## 3. 摇杆

- PSP 摇杆、3DS Circle Pad 先当 8 方向用：推过死区算方向，不做力度。
- PC 用 I/J/K/L 模拟（PPSSPP 默认）。
- 以后要力度，再加两个轴（-1..1）。

## 4. 界面确认/取消

- 工程设置：ui_confirm、ui_cancel。
- 日版：确认 = ○（3DS A），取消 = ×（3DS B）。
- 美版：确认 = ×（3DS B），取消 = ○（3DS A）。
- 键位页给一个“日版/美版”开关，改这两个值。
- 界面读这两个设置；玩法规则不碰。

## 5. 存储与编辑

- 存在工程里（keymap 一节），或 keymap.ini。
- 编辑器“键位”页：一个按钮一行，点格子按键就绑上；恢复默认。
- 运行时读不到就用默认值，不崩。

## 6. v1 不做

- 自定义“动作名”（跳/攻击）——只提供物理按钮。
- 掌机按钮重映射（掌机固定）。
- 模拟摇杆力度。
- 组合键/宏。
- 手柄（XInput）——以后加。

## 7. 备注

- PPSSPP 的 Tab/Esc/Delete 等是模拟器功能键，不进入游戏。
- PPSSPP 版本不同默认值可能微调；以键位页为准。
- 之前说过“Z/X 不要”，现按方案 A 保留 PPSSPP 原样；以后在键位页改。
